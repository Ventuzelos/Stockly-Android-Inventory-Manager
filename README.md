# Stockly — Android Inventory Manager

Aplicação mobile de gestão de stock desenvolvida em Kotlin para Android.

O projeto permite gerir produtos e respetivas quantidades em stock através de uma interface moderna, intuitiva e responsiva.

## Estado do projeto

🚧 Em desenvolvimento.

## Objetivos

* Implementar uma aplicação Android funcional para gestão de stock;
* Aplicar boas práticas de desenvolvimento em Kotlin;
* Persistir os dados localmente através de Room;
* Criar uma interface baseada em Material Design 3;
* Desenvolver um projeto completo para apresentação em portefólio.

## Funcionalidades planeadas

* Splash Screen personalizada;
* Sistema de autenticação local;
* Dashboard com resumo do inventário;
* Registo de produtos;
* Consulta de produtos;
* Pesquisa por nome;
* Filtro por categoria;
* Ordenação pela quantidade em stock;
* Edição e eliminação de produtos;
* Alertas de stock reduzido;
* Histórico de movimentos de stock;
* Logout.

## Tecnologias

* Kotlin;
* Android SDK;
* XML Layouts;
* Material Design 3;
* Room Database;
* RecyclerView;
* ViewModel;
* Kotlin Coroutines;
* View Binding;
* Navigation Component;
* DataStore.

## Arquitetura

A aplicação será desenvolvida com uma arquitetura organizada por camadas:

* `data` — persistência local e repositórios;
* `domain` — modelos e regras de negócio;
* `ui` — ecrãs, componentes e ViewModels;
* `utils` — funções e recursos auxiliares.
